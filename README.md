# eBarangay
E-Barangay: A Barangay Service Request System

# About the System
eBarangay is a web-based system designed to make barangay services easier and more convenient for residents. It allows residents to submit service requests online and track the status of their requests.

# Features
- User Registration and Login
- Service List
- Online Service Request
- Requirements Submission
- Request Tracking
- Status Updates
- Claim Date
- Request History
- Notifications
- Request Management for Barangay Officials

# Users

Residents
Residents can register, request barangay services, submit requirements, and track their requests.

Barangay Officials
Officials can manage requests, verify submitted information, update request statuses, and manage records.
